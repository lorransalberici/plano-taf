# Plano TAF — 8 semanas

Plano de treino para o TAF da Marinha (corrida 3.200 m e barra fixa), com calendário datado, montagem dos treinos para o app adidas Running e marcação de dias concluídos.

Arquivo único, sem dependências. Publicado no GitHub Pages.

## Como publicar

1. No GitHub, crie um repositório novo (pode ser público ou privado — Pages funciona nos dois em conta gratuita hoje).
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Em **Branch**, escolha `main` e a pasta `/ (root)`. Salve.
6. Espere de 1 a 2 minutos. O endereço aparece na própria página de Settings, no formato:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## No celular

Abra o endereço no Chrome, toque no menu e escolha **Adicionar à tela inicial**. Ele passa a abrir como se fosse um app.

## Sobre o salvamento

As marcações e anotações ficam guardadas no `localStorage` do navegador do aparelho.

- Funcionam offline depois da primeira visita.
- **Não** sincronizam entre celular e computador.
- Somem se você limpar os dados do navegador ou desinstalar.

Por isso existe o botão **Baixar backup** no rodapé. Ele gera um `.json` que o botão **Restaurar** lê de volta.
